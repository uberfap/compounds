# Compounds — static edition

Compounds is a daily puzzle about chemical names, structures, origins, and pharmacology. Group sixteen compounds into four sets of four.

[Play the static edition](https://uberfap.github.io/compounds/)

## Run locally

Open `index.html` in a browser. The page includes its published puzzle batch and stores progress in the browser. Add `?debug=1` to show the day navigation controls.

## Publish

In the repository's **Settings → Pages**, select **Deploy from a branch** and choose **legacy-pages** with **/(root)**. The site is ready to serve as committed. The `/dist/` URL redirects to the site root and preserves query parameters and fragments.

The [full-stack edition](https://github.com/uberfap/compounds/tree/ui-polish) includes server-backed attempts, statistics, and leaderboards.
